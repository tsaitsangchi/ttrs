TipTop 使用紀錄匯出需求

對象
TipTop 資料庫管理員（DBA）
用途
決定新系統的移植範圍與先後順序
性質
只執行 SELECT，不修改任何資料；結果只含彙總數字
希望完成
一週內，建議於離峰時段執行

為什麼需要這些資料

TipTop 標準程式約一萬支、客製程式約一千兩百支，實際在用的只是其中一部分。我們要依「哪些程式真的有人在用、用得多頻繁、資料量多大」排出移植順序，並決定哪些程式不移植。這些紀錄只在正式區，新系統依規定只連測試區（TOPTEST），所以需要請您代為匯出。

完整 SQL 附在本頁最後，也可以直接使用專案檔案 scripts/tiptop/usage_export.sql。每段查詢的結果請存成 UTF-8、含標題列的 CSV，檔名如下：

資料保護

  • 所有查詢都是彙總（COUNT、MAX），不匯出使用者代號、姓名或任何業務資料內容。
  • Q6 只讀資料庫統計資訊（num_rows），不會掃描業務資料表。
  • 匯出檔只供移轉專案規劃使用，不進版控。

另外想請您確認三件事

  1. zu_file 是否有持續寫入？若 q3_check.csv 的最新日期很舊或筆數為 0，我們會改用 Q4、Q5 判斷使用情況。
  2. 測試區 TOPTEST 最近一次從正式區複製是什麼時候？若是近期複製，之後的資料分析可直接在測試區進行。
  3. 從開發環境連 GSMC_TOPTEST 時，TCP 可連但沒有 TNS 回應，是否有防火牆或監聽設定需要調整？

完整 SQL

-- Q1 營運中心清單 → q1_plants.csv
SELECT azp01 AS plant, azp02 AS plant_name, azp03 AS db_schema, azp053 AS is_erp_db
FROM azp_file
ORDER BY azp01;

-- Q2 程式登錄清單 → q2_programs.csv
SELECT zz01 AS program, zz011 AS module, zz03 AS program_type, gaz03 AS name_zh_tw, gaz05 AS custom_code
FROM zz_file
LEFT JOIN gaz_file ON gaz01 = zz01 AND gaz02 = '0'
ORDER BY zz01;

-- Q3 近 12 個月程式執行次數 → q3_program_runs.csv
SELECT zu01                             AS program,
       COUNT(*)                         AS runs,
       COUNT(DISTINCT zu04)             AS users,
       COUNT(DISTINCT TO_CHAR(zu02, 'YYYYMM')) AS active_months,
       ROUND(SUM(zu05), 1)              AS total_minutes,
       MIN(zu02)                        AS first_run,
       MAX(zu02)                        AS last_run
FROM zu_file
WHERE zu02 >= ADD_MONTHS(TRUNC(SYSDATE), -12)
GROUP BY zu01
ORDER BY runs DESC;

-- Q3 檢查 zu_file 是否有寫入 → q3_check.csv
SELECT COUNT(*) AS total_rows, MIN(zu02) AS earliest, MAX(zu02) AS latest FROM zu_file;

-- Q4 近 12 個月各程式異動筆數（每個營運中心 schema 各執行一次）→ q4_changes_<schema>.csv
SELECT azo01                AS program,
       COUNT(*)             AS changes,
       COUNT(DISTINCT azo02) AS users,
       MAX(azo03)           AS last_change
FROM azo_file
WHERE azo03 >= ADD_MONTHS(TRUNC(SYSDATE), -12)
GROUP BY azo01
ORDER BY changes DESC;

-- Q5 有效使用者被授權的程式 → q5_granted.csv
WITH active_users AS (
    SELECT zx01, zx04 FROM zx_file
    WHERE zxacti = 'Y' AND (zx18 IS NULL OR zx18 >= TRUNC(SYSDATE))
),
user_classes AS (
    SELECT zx01, zx04 AS class_code FROM active_users
    UNION
    SELECT w.zxw01, w.zxw04 FROM zxw_file w
    JOIN active_users u ON u.zx01 = w.zxw01
    WHERE w.zxw03 = '1'
),
grants AS (
    SELECT c.zx01, y.zy02 AS program FROM user_classes c
    JOIN zy_file y ON y.zy01 = c.class_code
    UNION
    SELECT w.zxw01, w.zxw04 FROM zxw_file w
    JOIN active_users u ON u.zx01 = w.zxw01
    WHERE w.zxw03 = '2'
)
SELECT program, COUNT(DISTINCT zx01) AS active_users
FROM grants
GROUP BY program
ORDER BY active_users DESC;

-- Q6 各資料表筆數（IN 清單請換成 Q1 所有營運中心的 db_schema，大寫）→ q6_table_rows.csv
SELECT owner, table_name, num_rows, last_analyzed
FROM all_tables
WHERE owner IN ('DS' /* , 'DS1', 'DS2' ... */)
ORDER BY owner, num_rows DESC NULLS LAST;

-- Q7 各部門有效使用者人數 → q7_active_users.csv
SELECT zx03 AS dept, COUNT(*) AS active_users
FROM zx_file
WHERE zxacti = 'Y' AND (zx18 IS NULL OR zx18 >= TRUNC(SYSDATE))
GROUP BY zx03
ORDER BY active_users DESC;
欄位依據 TipTop 資料表定義：zu、zz、zx、zy、zxw、gaz（azz 模組）與 azo、azp（aoo 模組）的 .sch 檔。如有欄位不符或查詢太慢，請告知，我們再調整。
