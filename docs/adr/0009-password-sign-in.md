# ADR 0009：以使用者代號＋Web 密碼登入（取代公司 SSO）

- 狀態：已採用（Key User，2026-11-04，W1–W12 依草稿確認）
- 取代：ADR 0006 §1（公司 SSO／OIDC）、§2 公司帳號綁定、§3 中密碼相關欄位不移植的部分；§4–§8（權限、AI、稽核）不變
- 相關：`specs/features/azz/web_password.feature`（草稿）、`specs/features/azz/sign_in.feature`

## 背景

Key User 決定 TTRS **只用密碼登入、不接公司 SSO**：使用者維護要有 Web 密碼，作為 Web 登入的驗證。

TipTop 的做法：

- **密碼欄位**（zx_file）：zx10 Web 密碼（varchar2(40)，以 cl_user_encode 編碼後存放）、zx16 密碼更新日、
  zx17 此密碼已登入次數、zx19 下次登入須改密碼、zx20 已試誤次數。
- **使用者維護（p_zx）**：新增時密碼預設＝使用者代號、zx19＝Y（p_zx.4gl:447、:561）；
  管理員改密碼時 zx19 設為 Y（:640-650）；密碼最多 20 字（:644）；「解除鎖定」把 zx20 歸零（user_unlock，:367-400）。
- **登入（weblogin）**：帳號有效、未鎖定（zx20 < gbt10）、未過期（zx18）→ 密碼正確（錯誤時 zx20＋1）→
  密碼期限（gbt01＝1 依天數 gbt02／gbt01＝2 依次數 gbt03，gbt04 天前提醒）→ 成功時 zx20 歸零（weblogin.4gl:426-620）。
  密碼空白、不符現行密碼規則或 zx19＝Y 時，要先改密碼才能進入（:329-388，webpasswd）。
- **改密碼（webpasswd）**：輸入舊密碼、新密碼、確認；最多 20 字；依 gbt05 最小長度、gbt06 複雜度（Y 不可含帳號、
  M 再須含數字、S 再須含符號）、gbt08 可否與舊密碼相同檢查；成功時 zx16＝今天、zx17＝0、zx19＝N（webpasswd.4gl:67-150）。
- **帳號稽核原則（gbt_file，p_passpriv 維護）**：系統一筆（gbt00＝0）。
- 客製 FUN-C60025（2022，TSC）在 Portal SSO 進入時取消了密碼規則；改用密碼登入後此客製不再適用。

## 決策

1. **登入方式**：Web 登入畫面輸入使用者代號（zx01）與 Web 密碼；不接公司 SSO。`user_account` 的公司帳號欄位
   （idp_username、idp_subject）保留不用（W8）。
2. **密碼存放**：只存 **Argon2id 雜湊**（含隨機 salt），不存明文、不可還原；TipTop 的 zx10 編碼值不轉入（W1）。
3. **使用者維護**：新增「Web 密碼」欄位（只能輸入新密碼，畫面不顯示既有密碼）與「下次登入須改密碼」（zx19）；
   新增使用者時密碼預設＝使用者代號並須改密碼（同 TipTop）；新增「解除鎖定」動作（user_unlock）。
4. **登入檢查順序**照 weblogin：帳號（存在、有效、未過期、未鎖定）→ 密碼 → 密碼期限 → 須改密碼 → 營運中心
   （sign_in.feature 的營運中心規則不變）。
5. **改密碼**作業（webpasswd → `change-password`）：登入後隨時可改；須改密碼時登入只能先改密碼。
6. **帳號稽核原則**（gbt_file）移植為系統參數，供登入與改密碼使用；維護畫面（p_passpriv）另案移植，
   移植前用起始資料（W5）。
7. **連線**：伺服器端連線＋HttpOnly cookie（`SameSite=Lax`，正式環境經 nginx 走 HTTPS 時加 `Secure`）；
   閒置 30 分鐘、最長 12 小時（W11）。

## 影響

- ADR 0006 §1、§2 改為本 ADR；§3 的 zx10、zx16、zx17、zx19、zx20、gbt_file 改為移植。
- `sign_in.feature` 中「公司帳號（識別碼）登入」的情境改為「使用者代號＋密碼登入」；營運中心規則（SQ4–SQ8）不變。
- legacy-map：zx10 → `password_hash`（不轉值）、zx16 → `password_changed_on`、zx17 → `password_use_count`、
  zx19 → `password_change_required`、zx20 → `failed_sign_in_count`；gbt_file → 帳號稽核原則系統參數。
