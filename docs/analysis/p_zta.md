## 2. Query (p_zta_cs, 4gl:596)

Query fields: zta01, gat06, zta07, zta17, gat07, zta10, zta05, zta06, zta11, zta12 (Oracle).
gat03/gat04 (names) are **not** queryable. Results are sorted by zta01.

## 3. Add / modify (p_zta_i, 4gl:1375)

- zta01 must not already exist (-239). Customer editions automatically get the `tc_` prefix.
- gat06 and gat07 are required (AFTER INPUT, 9033).
- When gat03/gat04 are blank, CONTROLP (search) opens p_tabname to maintain them in every language.
- Add/modify/delete requires DBA privilege (azz-108).

## 4. Body maintenance

- 欄位單身 (p_zta_b), 索引單身 (p_zta_d), Constraint 單身 (p_zta_c): edit columns/indexes/constraints and **produce DDL** (create/alter).
- 維護欄位說明 (p_zta_fld_desc): opens p_feldname (gaq maintenance).
- 維護系統別及檔案名稱 (p_zta_tab_desc): opens p_tabname (gat maintenance).

## 6. Gaps from the current TTRS screen

User decisions (2026-10-30): items 1, 2, 3 and 4 adopted (屬性 derived by rule); item 5 adopts 屬性; item 6 adds only Ref. Constraint Name; item 7 is not added.


1. **Field tab column order and labels**: change to 欄位名稱 (column code), 型態, 長度, 不允許 null, 預設值, 屬性, 欄位說明 (gaq03), 額外說明 (gaq05).
   The current version uses 欄位代碼 / 型別 / 不可空白, labels gaq03 as 欄位名稱, and has no 屬性 column.
2. **Defaults should drop quotes and type casts**: PostgreSQL shows `'5'::text`; TipTop rules display it as `5`.
3. **屬性 (ztb05 / ztc05 / ztd12)**: TTRS has no zte_file (not ported). Should it be derived from TipTop's default rule (`tc_`/`ta_` → c customise, otherwise p 標準), or left off?
4. **Upper tab and field labels**: should they follow TipTop wording (主畫面/狀態, 檔案編號, 系統別, 檔案類別, 檔案名稱, 檔案目的)?
   They currently read 主要資料/資訊, 資料表代碼, 模組, 類型, 表名稱, 表目的.
5. **Index tab**: add 屬性 (ztc05)?
6. **Constraint tab**: add Delete Rule / Status / Validated (readable from pg_catalog; needs a backend change) and Ref. Owner / Ref. Constraint Name?
7. **Query**: add zta05/zta06 (產生日期/產生者) and zta11/zta12 (上游/下游)?
8. **Column description language**: TipTop shows only the user's language. TTRS falls back to Traditional Chinese per ADR 0005 (an adopted decision, so it stays).
9. **Fields not ported** (decided earlier in the spec): zta02, zta07, zta17, lockmode, zta10.
